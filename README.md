							# RDRS
					Ransomware Defense And Response System
A defensive cybersecurity application that monitors file-system and process activity to detect ransomware-like behavior and generate alerts.
	it is built usisng watchdog psutil, pydantic, pyyaml, loguru, sqlalchemy, fastapi, uvicorn, reportlab, jinja2, pytest and pytest-cov. it can be run in an python on ubuntu
